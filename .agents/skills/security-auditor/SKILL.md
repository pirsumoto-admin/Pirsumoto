# Security Auditor Skill

Use this skill to audit code for security issues, vulnerabilities, and best practice violations.

## Guidelines
1. Check for hardcoded credentials, API keys, and tokens.
2. Ensure proper input validation and sanitization is performed.
3. Check for common vulnerabilities (e.g., SQL injection, XSS, insecure deserialization).
4. Review access control, authorization, and authentication logic.
5. Provide actionable remediation steps for any discovered vulnerabilities.
