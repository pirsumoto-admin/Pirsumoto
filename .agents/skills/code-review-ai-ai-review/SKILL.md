# AI Code Review Skill

Use this skill when performing code reviews on new features, bug fixes, or pull requests.

## Guidelines
1. Verify that the code follows standard conventions and best practices for the language and framework.
2. Look for potential performance bottlenecks, infinite loops, or memory leaks.
3. Suggest improvements for code readability, maintainability, and modularity.
4. Ensure that the code includes adequate error handling.
5. Check if appropriate tests are included, or suggest areas that require test coverage.
